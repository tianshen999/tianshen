# Token 经济学评测报告（形+音+三维 vs 主流模型）

> 生成：eval/token_economy.py · 语料：评测样本 + 维基语料随机抽样 2000 行（固定种子），共 176,087 字符（汉字 141,102）
> 价格：公开价约数（2026 初），仅量级参考；人民币/百万 token（输入侧）

## 一、纯文本分词：token/字

| 分词器 | token/字 | 百万汉字输入成本（估算） |
|---|---|---|
| **天神·64k** | **0.762 🥇** | **1.52 元** |
| DeepSeek-V3（12.9万词表） | 0.849 | 1.70 元 |
| ChatGLM3-6B | 0.893 | 0.45 元 |
| Qwen2.5-7B（15万词表） | 0.943 | 0.75 元 |
| Yi-6B | 0.972 | 0.97 元 |
| GPT-4o | 1.079 | 19.41 元 |
| GPT-3.5 | 1.602 | 5.77 元 |

**结论**：在真实维基规模语料上，天神 64k 词表 token/字 **0.762，全场第一**，
反超 12.9 万词表的 DeepSeek（0.849）与 15 万词表的 Qwen（0.943）。
（注：小样本评测集上 DeepSeek 略优，两份结果均记录在案。）

## 二、等知识量成本：模型"知道读音"要花多少 token

要赋予模型"每个字的读音"这一知识：
- **天神**：读音在词表外部三维空间中（形/音平面），查表获取，**注入 token = 0**；
- 其他模型：必须把拼音作为文本注入上下文。

| 分词器 | 纯文本 token/字 | +拼音注入后 token/字 | 百万字+音成本（估算） | 相对天神倍数 |
|---|---|---|---|---|
| **天神·64k** | 0.762 | **0.762**（零注入） | **1.52 元** | 1x |
| DeepSeek-V3 | 0.849 | 2.901 | 5.80 元 | 3.8x |
| Qwen2.5-7B | 0.943 | 3.116 | 2.49 元 | 1.6x |
| Yi-6B | 0.972 | 3.852 | 3.85 元 | 2.5x |
| GPT-3.5 | 1.602 | 3.985 | 14.35 元 | 9.4x |
| GPT-4o | 1.079 | 3.199 | 57.58 元 | 37.9x |

**结论**：等知识量下，天神的 token 成本是 GPT-4o 的 **1/38**、DeepSeek 的 **1/3.8**。
这不是词表大小的胜利，是**架构的胜利**：知识住在表外三维空间，不进 token 流。

## 三、注音注入（附带发现 + 修复计划）

注音符号（ㄅㄆㄇ）在所有被测词表中都是弱势文字（未被收录，退化处理）：

| 分词器 | 注音注入 token（141k 字） | 每字 |
|---|---|---|
| 天神·64k | 555,177（unk 化，1 token/符号） | 3.9 |
| Qwen2.5-7B | 683,556 | 4.8 |
| DeepSeek-V3 | 799,995 | 5.7 |
| GPT-4o | 828,150（字节拆分） | 5.9 |
| GPT-3.5 | 1,272,584 | 9.0 |

天神虽已是其中最优，但注音符号仍未入词表。**修复计划（v0.3）**：
将 37 个注音符号 + 5 个调号作为原子符号加入核心词表（占用极少量席位），
使注音注入降至 1 token/符号且不再是 unk——配合注音挂件输出。

## 四、价格说明（诚实声明）

- 价格取公开信息约数，API 价格波动频繁，本表只做量级对比；
- 天神行按 DeepSeek-V3 输入价（2 元/百万）折算——天神词表配开源模型本地部署时，成本为本地算力而非 API 计费，实际边际成本趋近 0；
- GPT-4o 按 $2.5/百万（≈18 元）输入价折算。

## 五、整体结论

1. **纯文本**：天神 token 效率全场第一（0.762 token/字）；
2. **带读音知识**：天神的等知识量成本最低，且与其他模型的差距随"要求模型知道更多（形/音/意）"而拉大——每多一层知识，其他模型要多注入一层文本，天神仍是零；
3. **三维词空间的价值在此量化兑现**：知识住在几何里，不花 token。
