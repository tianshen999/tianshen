# 向量平面设计定案（v0.3a：形平面 F 与音平面 P）

> 状态：设计定案（v0.3a 修订 1：判定准则分层 + 特征加权）。
> 相关决策：ADR-021（真三维词空间）、docs/07（深度分析）。

## 0. 修订记录

- **修订 1（首轮证书后）**：
  1. 判定准则从"PR/ER ≥ 0.8×秩"单档改为**三层判定**——塌缩（秩缺失）/ 谱集中（满秩但能量幂律分布）/ 通过（满秩且能量均匀）。理由：one-hot 词袋的天然频率不平衡（高频部首）导致谱集中，这是真实语言结构而非塌缩，需单独分档并配应对措施。
  2. 新增**特征加权**：词袋计数取平方根（sublinear tf，抑制高频部件/读音的谱主导）。
  3. twoNN 抽样前先**按向量去重**（重复向量导致 d1→0 使估计退化），并记录去重后样本量。
  4. 证书必须同时输出**原始与加权**两版并排对比，作为"应对措施有效"的证据。
- **修订 2（IDF 加权轮）**：行内平方根加权无效（PR 22.77→22.26）——集中来自"特征跨字频率"，改为**列向 IDF 加权**（log((N+1)/(df+1))+1）。效果：F 平面 PR 22.77→95.54，各向异性 0.35→0.17，谱显著摊平。
- **修订 3（零模型轮）**：绝对判据 0.8×秩 对稀疏结构化数据过严且解释失真——引入**置换零模型**（逐列打乱保留边际频率）：|z|>2 即"显著区别于随机"；z>0 = 散布型结构（无凝聚），z<0 = 凝聚型结构（如部首聚类——真实层级结构，非塌缩）。最终判定 = 秩满（无缺失维度）+ |z|>2（结构真实存在）+ 平面正交 + 形声 MI>0。

## 1. 总体约定

- 词空间 W = F ⊕ P ⊕ S。本阶段实现 F 与 P；S 留待意阶段。
- 每个平面独立构建、独立存储、独立检验；拼装时正交直和（向量拼接）。
- **归一化**：每个字符/词的平面向量做 L2 归一化（单位向量），保证余弦相似度在各平面内可直接计算。
- **词级聚合**：多字词的向量 = 其字符向量的**算术平均后 L2 归一化**（bag-of-glyphs / bag-of-phonemes）。理由：线性、可解释、长度无关；文档记为 v0.3a 方案，后续可升级为位置加权。
- **存储**：scipy 稀疏矩阵（.npz）+ 元数据 JSON（键表、维度定义、版本、构建参数）。

## 2. 形平面 F 特征方案（字符级）

| 特征组 | 维度 | 编码 | 数据源 |
|---|---|---|---|
| 部首 | 214 | one-hot（康熙部首序号 1~214；无数据 → 全零） | Unihan kRSUnicode |
| 原子部件 | N_c（动态，≈500~1500） | 词袋 one-hot（字符分解树中出现的原子部件；N_c=语料中实际出现的原子部件总数） | CHISE IDS 分解 |
| 结构类型 | 12 | one-hot（⿰⿱⿲⿳⿴⿵⿶⿷⿸⿹⿺⿻；取 IDS 一级运算符；无 IDS → 全零） | CHISE IDS |
| 笔画数 | 1 | 数值（kTotalStrokes，除以 64 归一；缺失 → 0） | Unihan kTotalStrokes |

- F 总维度 = 214 + N_c + 12 + 1（≈700~1700，稀疏）。
- **原子部件定义**：在 IDS 数据中作为他人部件出现、且自身无（或达到深度上限而无）进一步分解的字符；部件词汇表按语料频率排序构建。

## 3. 音平面 P 特征方案（字符级）

| 特征组 | 维度 | 编码 | 数据源 |
|---|---|---|---|
| 声母 | 24 | one-hot（21 声母 + 零声母 + 未知槽） | 音阶段拼音数据层 |
| 韵母 | 40 | one-hot（39 韵母 + 未知槽） | 同上 |
| 声调 | 6 | one-hot（1~4 声 + 轻声 + 未知） | 同上 |

- **多音字处理**：取该字全部读音的词袋（各读音 one-hot 求和，含声调信息），再 L2 归一化。理由：多音是真实的音系属性（挂谷检验中的独立性检验将专门测量其与形平面的形声关联）。
- P 总维度 = 24 + 40 + 6 = 70。

## 4. 挂谷检验模块：指标与判定准则

对每个平面（F、P）及拼装空间 W=F⊕P 依次计算：

### 4.1 满维检验
- **参与率 PR**：PR = (Σλᵢ)² / Σλᵢ²，λᵢ 为协方差（或 Gram 矩阵）特征值。报告 PR 与"标称维度"（特征矩阵的秩，即理论上可达到的最大 PR）。
- **有效秩 ER**（Roy–Vetterli）：ER = exp(−Σ pᵢ ln pᵢ)，pᵢ = λᵢ/Σλᵢ。
- **谱分布**：前 20 个奇异值 + 累计能量曲线（前 k 维解释方差比例）。
- **twoNN 本征维度**（补充指标）：先按向量去重，再随机抽样 3,000 点（余弦距离），ID ≈ ln2 / mean(ln r)；d1≈0 的点对剔除。
- **三层判定准则（修订 1）**：
  - **塌缩（COLLAPSED）**：实测秩 < 0.8 × 标称维度（维度缺失——真正的假三维）；
  - **谱集中（CONCENTRATED）**：秩满但 PR < 0.8 × 秩（能量幂律分布——高频特征主导几何）；
  - **通过（PASS）**：秩满且 PR ≥ 0.8 × 秩。
  - 塌缩 → 停摆排查；谱集中 → 启用特征加权后复检（加权版证书与原始版并排）。

### 4.2 独立性检验（F ⟂ P）
- 计算 F 与 P 的交叉协方差，做 CCA/奇异值分解，报告**最大典型相关系数 ρ_max** 与 **P 被 F 线性解释的方差比例 R²**。
- **判定与解读**：期望总体低相关；但**形声字**（如"湖"的部件"胡"标注其声）会带来真实的 F–P 关联——这是语言事实而非塌缩。检验报告必须：① 给出总体 ρ_max 与 R²；② 对"形声字"子集（部件表中读音相关的字符）单独统计，验证关联集中在形声字上；③ 结论按此解读，不强制零相关。

### 4.3 无塌缩/正交性检验（拼装）
- W = F⊕P 的 PR/ER 应与 F、P 各自之和接近（偏差 > 15% → 维度互相吞并预警）；
- **各向异性**：每平面内向量与均值向量的平均余弦（> 0.5 → 强各向异性预警；对 one-hot 词袋结构，中等各向异性属预期，需结合谱分布解读）。

### 4.4 证书输出
- JSON（全部指标原值）+ Markdown 报告（指标表、判定结论、形声字专章、特征消融）。

## 5. 严谨性要求

- 全部指标实现必须配单元测试（合成数据验证：已知维度的满秩随机矩阵 → PR/ER 应≈标称秩；塌缩矩阵（重复列）→ 检出塌缩；正交合成平面 → ρ_max≈0）。
- 随机种子固定（谱分解与抽样）。
- 每次构建记录数据版本（Unihan/IDS/CEDICT 哈希）入证书元数据，保证可复现。
