# 意平面设计定案（v0.3b：意平面 S 第一版）

> 状态：设计定案。相关：ADR-021（真三维）、docs/07（深度分析）、docs/08（形音平面与挂谷检验）。

## 0. 修订记录

- **修订 1（独立性检验首轮后）**：
  - 首轮 S v1（义素层）被 形⊕音 解释 R²=0.52 > 0.3 判据——v1 义素是"形部首的线性重编码"，未带来独立新维度（设计文档预言的失败模式，检验有效拦截）；
  - 新增**深义层**：义项关键词袋（维基词典释义文本经自家分词器分词，top-2000 实义词，IDF 加权，2000 维）；
  - S v2 = 义素层（432 维）+ 深义层（2000 维）。独立性检验分两档：总 R²（含合法形义同源重叠）与**深义层 R²（准入判据 < 0.3）**。
  - 结果：深义层被 形⊕音 解释 R² = **0.0189** ✅（判据通过，意带来真正独立的新维度）；总 R² = 0.52（形义同源，语言事实）。

## 1. 定位与范围

- 意平面 S 是三维词空间的第三个正交平面，本版（v0.3b）为**第一版**：
  - **义项层**：字/词是否具有中文义项、义项数量（数据：维基词典中文释义 dump（CC BY-SA）为主，Unihan kDefinition（英文释义）为补充存在性标记）；
  - **义素层**：**214 部首义素**（人工策管，中文本义）+ **部件义素聚合**（字符原子部件的义素聚合而来）；
  - 指称钩子（物理世界类目）留 v0.4（ADR-021 既定）。

## 2. 特征方案（字符级）

| 特征组 | 维度 | 编码 | 数据源 |
|---|---|---|---|
| 部首义素 | 214 | one-hot（字符所属康熙部首的义素槽；无部首 → 全零） | 部首义素表（人工策管，src/semantic/radical_semantics.py） |
| 部件义素聚合 | 214 | 词袋（字符分解树中每个原子部件的部首义素求和） | IDS 分解 + 部首义素表 |
| 中文义项 | 1 | 有维基词典中文释义 = 1 | zhwiktionary 解析结果 |
| 义项数量 | 1 | log(1+义项数)/log(1+max) 归一 | 同上 |
| 英文释义存在 | 1 | 有 kDefinition = 1 | Unihan |
| 多音标记 | 1 | 多音字 = 1（语义歧义信号） | 拼音数据层 |

- S 总维度 = 214 + 214 + 4 = **432**。
- **词级聚合**：与 F/P 一致——字符向量均值 + L2 归一化。
- **中文原生原则**：义素标签为中文（部首本义）；向量几何是语言中立的概念编号，中文是显示层。

## 3. 部首义素表（214 条，人工策管）

- 每条：部首字 → 本义（一词概括）。策管状态分三级：✅ 已校 / 🟡 待校（冷僻部首）。
- 存于 src/semantic/radical_semantics.py，随包开源；标注"待校"的条目欢迎社区修正——开源策管。

## 4. 独立性检验（意进入三维空间的准入关）

沿用 docs/08 修订 3 框架，对 S 执行并报告：

1. **满维/秩检验**：S 的秩与零模型 z——S 必须是真实结构（z 显著）；
2. **新维度证明（核心）**：S 对 F⊕P 的多输出岭回归 R²——**S 被形/音解释的方差必须低**（R² < 0.3 判据），证明意带来了形、音之外的新维度；反之若 R² 过高，说明 v1 义素只是形部首的线性重编码，需加深义素层；
3. **正交性**：S 与 F、S 与 P 的最大典型相关 ρ_max 报告（允许部首义与形之间的少量真实关联——如"氵→水义"正是汉字本有的形义联系，需与形声字专章同法解读）。

## 5. 几何演示与评测基准

- **同义/近义检索**：S 子空间内余弦最近邻。策管评测集（人工标注，开源）：探针词 → 期望关联词表（如 水→江河湖海泉、火→炎焰焚燃、心→情意怨慕），命中率 = 报告指标；
- **部首义聚类**：同部首字在 S 内的内聚度（轮廓系数类指标）；
- **跨平面演示**：输入词 → 形近（F）/ 音近（P）/ 义近（S）三列检索结果并排。

## 6. 已知边界（诚实声明）

- v1 义素为"部首义素"，粒度粗（214 类）；细粒度义素体系（如"液体/情感/工具"）留 v0.4+；
- 维基词典释义质量参差（开放编辑），义项层只取"存在性与数量"而非全文语义，规避噪声；
- kDefinition 为英文释义，仅作"存在性"特征，不进中文义项统计。
