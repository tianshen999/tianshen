# 天神（Tianshen）全景架构图 —— v0.3 收尾人工终审版

> 本文档是给项目所有者做**最终人工确认**用的全景图：一张图看懂整个系统由哪几层组成、
> 数据怎么流、闸门怎么把关、哪些成果已经落地、还差哪一步。
> 所有数字均取自当前工作区的真实产物（2026 年闸门 PASS 时的快照），非估算。

---

## 一、一句话总纲

天神 = **中文原生 AI 全栈体系**：从最底层的分词器开始就把中文当"第一等公民"，
按 **形 → 音 → 意** 三步构建一个**真三维词空间（W = F ⊕ P ⊕ S）**——
这是未来"通用机器人脑"的基底，基底维度决定大脑天花板。
简体为核心，繁体/拉丁/注音/发声全部是**可插拔挂件**；知识放在侧表，不占 token。

## 七、人工最终确认清单（请你逐条过目）

请你以所有者身份确认以下各条，确认后即可发我令牌，完成 v0.3 推送：

1. **架构分层**：六层（数据 → 形 → 音 → 意 → 评测校准 → 闸门发布）符合你的预期？
2. **核心哲学**：简体核心 + 四挂件（繁体/拉丁/注音/发声）；知识在侧表零 token——保持？
3. **真三维定案**：W = F⊕P⊕S 三平面正交（独立性 R²=0.02），作为未来通用机器人脑的 3D 基底——认可？
4. **闸门制度**：每次大版本强制自动审计+自动校准，失败禁止发布；新板块零声明接入（ADR-031）——认可？
5. **透明原则**：所有报告、证书、缺陷记录全部随发布公开（ADR-024）——确认？
6. **许可证**：GPL-3.0、无限开源、不在乎盈利——确认？
7. **发布节奏**：v0.1（形）、v0.2（音）已发布；v0.3（意）待推送——确认本版内容边界？
8. **下一步方向**（供选择，不阻塞本版）：
   - A. 真三维之后：字级→词级语义检索增强、反义/同义大探针集；
   - B. 向"通用机器人脑"迈进：给三维空间加"世界/时空/动作"维度（新板块，走 ADR-031 协议）；
   - C. 先沉淀：补全文档、出论文级技术报告、扩大开源社区。
