# 新板块接入协议（ADR-031）

> 用户制度（ADR-029）：每次大版本更新必须执行自动审计 + 自动校准。
> 本文回答："未来接入新板块（新平面、新特征族、新挂件）时，校准机制需要人工重新配置吗？"
>
> **结论：通用校准机制自动适用、零声明接入；领域探针必须每次人工策展。**
> 机制是自动的，判题是人工的 —— 两者分开，新板块不会绕过闸门，也不会被旧判题卡死。

---

## 一、自动适用的部分（新板块零声明即生效）

### 1. 结构依赖预算（维度证书自动计算）
- `src/semantic/kakeya_check.py` 的 `certify()` 默认 `auto_blocks=True`：
  不传 `block_sizes` 时，`detect_blocks()` 自动识别 one-hot 特征块（支撑集互斥归并），
  自动计算可达秩，判据"实测秩 ≥ 0.95 × 可达秩"自动生成。
- 新板块代码只需一行：`KC.certify("新板块名", X)` —— 与现有平面同样的证书与判据，无需声明块结构。
- 例外：拼装平面（W=F⊕P 等组合空间，跨平面冗余属预期）显式传 `auto_blocks=False` 豁免。

### 2. 闸门自动发现（证书落盘即被判定）
- 证书按命名约定落盘：`artifacts/semantic/<板块>_certificates.json`。
- `tools/gate_check.py` 自动扫描全部 `*_certificates.json`：
  - 含 `achievable_criterion` 的证书 → 结构预算判据自动适用；
  - 含 `independence_vs_FP` 的证书 → 独立性判据自动适用（R² < 0.3）；
  - 旧式 `rank_criterion` 兜底判据同样自动适用。
- 新板块的证书文件只要放对目录，发布闸门就把它纳入判定 —— 不修改 gate_check.py。

### 3. 通用校准层（直接调用，一次到位）
| 校准项 | 函数 | 说明 |
|---|---|---|
| IDF 列加权 | `weighting.idf_transform / idf_weights` | 常见列降权（ADR-030） |
| 死列剪枝 | `def_keywords.build_matrix(prune_dead=True)` | 全零列移除 |
| 共线列合并 | `weighting.merge_collinear(X, block_sizes)` | 逐块合并完全同形列，保留块结构 |
| 简繁校准 | `script_tag.to_simplified` | 简体核心原则：特征文本先转简 |

这些是通用函数，新板块的数据清洗流程直接复用，无需重新推导。

### 4. 基础维度证书（certify 一次生成）
PR、有效秩、各向异性、twoNN 本征维度、置换零模型显著性 —— 与现有平面完全同构。

---

## 二、必须人工策展的部分（每个新板块一次，不是每次版本）

1. **领域探针**：如义近检索的 PROBES/ANTONYMS（`eval/semantic_bench.py`）。
   语义正确性只有人能定义 —— 机器可以自动"跑"探针，但不能自动"发明"正确答案。
2. **独立性参照**：新板块的"被解释 R²"相对谁做回归（形⊕音？全部旧板块之和？）。
   选参照平面是设计决策，不是校准参数。
3. **领域评测基线**：如多音消歧的 185 题判题集。判题集人工策展一次，之后每次版本自动复跑。
4. **audit_full 登记**（每条一行）：
   - 平面名加入 `tools/audit_full.py` 的键一致性/零向量检查列表；
   - 板块专属不变量（如"繁体挂件不得泄漏进核心"）写一段检查。

---

## 三、新板块接入清单（六步）

1. 特征矩阵落盘：`artifacts/semantic/<板块>_plane.npz` + `<板块>_plane.meta.json`（含 keys）。
2. 证书生成：`KC.certify("<板块>·IDF", X_idf)`（自动结构预算）+ 独立性检验 `KC.cross_analysis` 挂到 `independence_vs_FP`。
3. 证书落盘：`artifacts/semantic/<板块>_certificates.json`（命名约定即被闸门发现）。
4. 策展领域探针与判题集（一次性人工工作）。
5. audit_full 登记平面名与板块专属不变量（每条一行）。
6. 运行发布闸门 `tools/audit_gate.ps1` —— 新板块自动纳入全部判定，11 步 PASS 才可发布。

---

## 四、实现记录（本次落地）

- `kakeya_check.py`：新增 `detect_blocks(X)`；`achievable_rank(..., auto_blocks=True)` 支持自动分块；
  `certify(..., auto_blocks=True)` 默认自动启用；证书报告（.md）新增结构预算明细行。
- `tools/certify_planes.py` / `tools/certify_meaning.py`：拼装平面 W/W3 显式 `auto_blocks=False`（豁免）。
- `tools/gate_check.py`：证书自动发现（`*_certificates.json` 扫描），新板块零修改接入。
- `tools/e2e_check.py`：端到端贯通验证（一条文本走完 形→音→意 + 四挂件路由），已入闸（第 6 步）。
- `tests/test_semantic.py`：新增 3 个测试（自动识别 one-hot 家族 / auto 预算与证书 / 显式分块与豁免）。
