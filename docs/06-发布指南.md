# 发布指南（保姆级，5 分钟完成）

> 目标：把 `release/tianshen-v0.1.zip` 发布到 GitHub（代码托管）。
> 你需要准备：一个能收邮件的邮箱。

## 第一步：注册 GitHub（2 分钟）

1. 浏览器打开 **https://github.com/signup**
2. 依次填写：邮箱 → 密码 → 用户名（建议 `tianshen` 或你的昵称+数字）→ 完成人机验证
3. 打开邮箱，点击 GitHub 发来的验证邮件里的链接
4. 登录进去看到仪表盘 → 注册成功

## 第二步：创建仓库（1 分钟）

1. 登录后，点击右上角 **+** 号 → **New repository**
2. Repository name 填：`tianshen`
3. 选 **Public**（公开，符合开源）
4. 其他什么都不用动，点绿色 **Create repository**

## 第三步：上传发布包（2 分钟）

**方法 A（最简单，推荐）——网页拖拽：**
1. 先解压 `release/tianshen-v0.1.zip`
2. 回到刚创建的仓库页面，点 **uploading an existing file**（蓝色链接）
3. 把解压出的**文件夹里的全部内容**拖进浏览器上传区
4. 下方绿色按钮 **Commit changes** 点击提交
5. 完成！仓库地址形如 `https://github.com/你的用户名/tianshen`

**方法 B——发布 zip 附件：**
1. 仓库右侧栏找 **Releases** → **Create a new release**
2. Tag 填 `v0.1`，标题写「天神 v0.1：中文原生分词器」
3. 把 `tianshen-v0.1.zip` 拖进附件区 → **Publish release**

## （可选）第四步：HuggingFace 发布模型

1. 打开 **https://huggingface.co/join** 同样用邮箱注册
2. 登录后点右上角头像 → **New Model**
3. Model name 填 `tianshen-tokenizer`，License 选 **GPL-3.0**
4. 创建后点 **Files** 标签 → **Add file** → **Upload files**
5. 把解压后 `models/` 文件夹里的 7 个文件全部拖进去提交

## 方案 C（最省事）：生成令牌，AI 全程代发

> 你只做两件事：注册账号 + 生成令牌；剩下的建仓库、传文件、发 release 全部自动完成。

### 1. 生成 GitHub 令牌（1 分钟）

1. 登录 GitHub → 右上角头像 → **Settings**
2. 左侧最底部 **Developer settings** → **Personal access tokens** → **Tokens (classic)** → **Generate new token (classic)**
3. Note 填 `tianshen-publish`；Expiration 选 **7 days**（够用）
4. 权限勾选：**repo** 这一项（整行勾上）
5. 拉到最下面点 **Generate token**
6. 把生成的 `ghp_` 开头的字符串复制下来，**发给 AI**
7. （安全：发布完成后可随时回到这个页面点 Delete 吊销令牌）

### 2. AI 代发流程

AI 会用令牌执行：创建仓库 → 上传全部 50 个文件 → 发布 v0.1 release 与 zip 附件。
全程不需要密码。

### 3. 发布完成后

- 回到令牌页面**吊销令牌**（推荐）；
- 或保留到"音"阶段发布时继续用（到期自动失效）。

## 安全提醒

- **不要把你的密码发给任何人（包括我）**；
- 若让我代劳推送，只提供**访问令牌**（可随时在设置里吊销），不要提供密码。
